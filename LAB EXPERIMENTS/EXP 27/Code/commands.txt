EXPERIMENT 27 — COMMITTING AND PUSHING CHANGES TO GITHUB

Prerequisite: Clone a GitHub repository and make local file edits.

1. Open terminal in the repository folder.
2. Check the working tree:
   git status

3. View modifications:
   git diff

4. Stage all changes:
   git add .

5. Verify staged changes:
   git status

6. Commit:
   git commit -m "Update project files"

7. Push to GitHub:
   git push origin main

8. Refresh the GitHub repository page to verify changes.

If your current branch is not main, check it using:
   git branch

To push the current branch:
   git push origin YOUR_BRANCH

If the remote is not configured:
   git remote -v
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
