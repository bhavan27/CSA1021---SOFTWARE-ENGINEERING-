# Git Commit and Push Demonstration

This project demonstrates the Git workflow for recording local changes and uploading them to GitHub.

## Project
A simple sample project used for practicing Git commits and pushes.

## Latest Change
This README was updated to demonstrate committing and pushing modified files.

## Git Workflow
1. Modify a file.
2. Check the changes.
3. Stage the file.
4. Commit the staged changes.
5. Push the commit to GitHub.
