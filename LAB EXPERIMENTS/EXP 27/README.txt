EXPERIMENT 27: COMMITTING AND PUSHING CHANGES TO GITHUB

Aim:
To record local file modifications using Git commits and upload the commits to a remote GitHub repository.

Requirements:
- Git installed
- Existing cloned GitHub repository
- GitHub account and push permission
- Terminal or Command Prompt

Procedure:
1. Open the local repository folder.
2. Modify one or more project files.
3. Check file changes using git status.
4. Review changes using git diff.
5. Stage the modified files using git add.
6. Verify staged files.
7. Commit changes with a descriptive commit message.
8. Push the commit to the GitHub remote repository.
9. Refresh GitHub and verify the updated files and commit history.

Result:
Local changes were staged, committed, and successfully pushed to the remote GitHub repository.
