# Contributing Guidelines

1. Do not commit directly to `main`.
2. Create a task-specific branch:
   `git switch -c feature/<feature-name>`
3. Use meaningful commit messages, such as:
   `feat: add welcome message`
   `docs: update project README`
   `fix: correct output formatting`
4. Push your branch:
   `git push -u origin <branch-name>`
5. Open a Pull Request against `main`.
6. Describe the changes and testing performed.
7. Request at least one teammate review.
8. Resolve feedback before merging.
