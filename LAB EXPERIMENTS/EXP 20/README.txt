EXPERIMENT 20: TEAM PROJECT REPOSITORY WITH BRANCHES, PULL REQUESTS AND README DOCUMENTATION

Aim:
To create a collaborative GitHub repository, manage development using branches, submit Pull Requests, and maintain project README documentation.

Requirements:
- Git
- GitHub account
- Team members / collaborators
- Terminal or Git Bash

Procedure:
1. Create a GitHub repository for the team project.
2. Clone the repository to the local system.
3. Add the project source code and README documentation.
4. Commit the initial version to the main branch.
5. Add team members as collaborators.
6. Create a feature branch for each task.
7. Make changes and commit them with meaningful messages.
8. Push feature branches to GitHub.
9. Create Pull Requests targeting the main branch.
10. Review Pull Requests and provide feedback.
11. Modify code based on review comments if needed.
12. Merge approved Pull Requests.
13. Verify merged changes and repository history.
14. Update README and team contribution documentation.

Result:
A team project repository was created and organized using Git branches, Pull Requests, README documentation, and collaborative code review.
