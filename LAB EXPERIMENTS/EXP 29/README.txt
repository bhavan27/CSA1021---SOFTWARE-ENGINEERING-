EXPERIMENT 29: FEATURE BRANCH (feature-login) AND PULL REQUEST

Aim:
To create a feature branch named feature-login, implement a login UI feature, push it to GitHub, and create a Pull Request for review and merging.

Requirements:
- Git installed
- GitHub account and repository
- Internet connection
- Text editor / VS Code

Procedure:
1. Clone the repository and navigate into it.
2. Update the main branch using git pull.
3. Create and switch to feature-login using git checkout -b feature-login.
4. Implement the login feature in the project.
5. Review changes using git status and git diff.
6. Stage and commit the feature changes.
7. Push feature-login to GitHub.
8. Open GitHub and create a Pull Request from feature-login into main.
9. Review the changes and merge the Pull Request if permitted.
10. Pull the merged changes into the local main branch.

Result:
A feature branch named feature-login was created, pushed to GitHub, and a Pull Request was opened for review.
