EXPERIMENT 30: FORKING, FEATURE BRANCH AND PULL REQUEST TO THE ORIGINAL REPOSITORY

Aim:
To fork an original GitHub repository, clone the fork locally, create a feature branch, implement changes, push the branch to the fork, and submit a Pull Request to the original repository.

Requirements:
- Git
- GitHub account
- Internet connection
- Text editor / VS Code
- An original repository that accepts contributions

Procedure:
1. Open the original repository on GitHub and click Fork.
2. Create the fork under your GitHub account.
3. Clone your fork using git clone.
4. Add the original repository as the upstream remote.
5. Create a feature branch named feature-contribution.
6. Make a change to the project files.
7. Review changes, stage them, and commit.
8. Push the feature branch to your fork.
9. Open GitHub and create a Pull Request from your fork's feature branch to the original repository's main branch.
10. Submit the Pull Request for review.

Result:
The original repository was forked, a feature branch was created in the fork, changes were committed and pushed, and a Pull Request was submitted to the original repository.
