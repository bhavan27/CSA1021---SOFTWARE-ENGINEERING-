# EXP 10 – MoSCoW Prioritization of Library Management System Requirements

## Aim
To identify and prioritize the requirements of a Library Management System using the MoSCoW prioritization technique.

## MoSCoW Categories
- **Must Have:** Essential requirements for the system to function.
- **Should Have:** Important requirements that are not critical for the initial release.
- **Could Have:** Desirable features that can be included if time and resources permit.
- **Won't Have (This Release):** Features intentionally excluded from the current release.

## Procedure
1. Identify the functional requirements of the Library Management System.
2. Write each requirement clearly.
3. Evaluate the importance and necessity of each requirement.
4. Classify requirements into Must Have, Should Have, Could Have, and Won't Have.
5. Review the classifications with stakeholders.
6. Record the prioritized requirements in a table.
7. Check that essential system functionality is included in Must Have.
8. Finalize the prioritization for release planning.

## Result
The Library Management System requirements were prioritized using MoSCoW, helping identify essential features and plan the release scope.
