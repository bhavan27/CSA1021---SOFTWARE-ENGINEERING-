GitHub Actions Secrets:
- DOCKERHUB_USERNAME: Docker Hub username
- DOCKERHUB_TOKEN: Docker Hub access token

Optional remote deployment secrets:
- SERVER_HOST: remote server IP/domain
- SERVER_USER: SSH username
- SERVER_SSH_KEY: private SSH key

Never put credentials directly in the workflow YAML or source code.
The included workflow builds and pushes to Docker Hub automatically. The remote SSH deployment section is commented out until server details and secrets are configured.
