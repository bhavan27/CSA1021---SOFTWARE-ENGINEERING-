EXPERIMENT 19 - CONTINUOUS DEPLOYMENT USING GITHUB ACTIONS

1. Create a GitHub repository.
2. Upload/push the contents of github_actions_cd_project to the repository.
3. In GitHub, open Settings -> Secrets and variables -> Actions.
4. Add repository secrets:
   DOCKERHUB_USERNAME = your Docker Hub username
   DOCKERHUB_TOKEN = your Docker Hub access token
5. Ensure the workflow file is at:
   .github/workflows/deploy.yml
6. Push a commit to the main branch.
7. Open the Actions tab and inspect the workflow run.
8. Verify the Docker image appears in Docker Hub.

Local test:
docker build -t github-actions-cd-app .
docker run -d --name github-actions-cd-app -p 5000:5000 github-actions-cd-app
Visit:
http://localhost:5000
http://localhost:5000/health

Optional local compose:
docker compose up --build
docker compose down

For deployment to a remote server:
- Add SERVER_HOST, SERVER_USER, SERVER_SSH_KEY as GitHub secrets.
- Prepare a remote server with Docker installed and SSH access.
- Uncomment and configure the remote deployment step in deploy.yml.
