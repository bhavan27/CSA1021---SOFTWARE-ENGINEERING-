EXPERIMENT 22: PUSH AND PULL DOCKER IMAGES USING DOCKER HUB

Aim:
To build a Docker image, push it to Docker Hub, pull it from Docker Hub, and run the downloaded image.

Requirements:
- Docker Desktop / Docker Engine
- Docker Hub account
- Terminal / PowerShell

Procedure:
1. Create a Docker Hub account and repository.
2. Create a sample Flask application and Dockerfile.
3. Build the Docker image locally.
4. Tag the image with the Docker Hub username and repository name.
5. Log in to Docker Hub using docker login.
6. Push the tagged image using docker push.
7. Verify the image in Docker Hub.
8. Remove the local tagged image if required.
9. Pull the image using docker pull.
10. Run the pulled image as a container.
11. Access the application through the browser.
12. Verify the running container and image.

Result:
The Docker image was successfully pushed to Docker Hub, pulled to the local system, and run as a container.
