EXPERIMENT 25: CREATING A GITHUB REPOSITORY AND PUSHING A README FILE

Aim:
To create a GitHub repository and push a README file from a local system using Git.

Requirements:
- Git installed
- GitHub account
- Terminal or Command Prompt
- Internet connection

Procedure:
1. Sign in to GitHub and create a new repository.
2. Create a local project directory.
3. Add the README.md file.
4. Initialize Git in the local directory.
5. Stage the README file.
6. Commit the staged file.
7. Set the main branch.
8. Add the GitHub remote repository URL.
9. Push the local commit to GitHub.
10. Refresh the repository page and verify the README.

Result:
A GitHub repository was created and the README file was successfully pushed from the local repository to GitHub.
