# My First GitHub Repository

## About
This repository demonstrates how to create a GitHub repository and push a README file using Git.

## Objective
To practice creating a repository, initializing Git locally, connecting it to GitHub, and pushing project documentation.

## Tools Used
- Git
- GitHub
- Terminal / Command Prompt

## Steps
1. Create a repository on GitHub.
2. Create a local project folder.
3. Initialize Git.
4. Add a README file.
5. Commit the changes.
6. Connect the local repository to GitHub.
7. Push the commit.

## Commands
```bash
git init
git add README.md
git commit -m "Add README"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Replace `YOUR_USERNAME` and `YOUR_REPOSITORY` with your own values.
