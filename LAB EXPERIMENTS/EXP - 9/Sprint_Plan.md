# Sprint Plan

## Project
Student Task Management System

## Sprint 1
**Duration:** 1 week  
**Sprint Goal:** Enable students to create and view tasks, and mark tasks as completed.

### Sprint Backlog
- Create task (3 story points)
- View task list (2 story points)
- Mark task completed (3 story points)
- Design task interface (2 story points)

**Total:** 10 story points

## Sprint 2
**Duration:** 1 week  
**Sprint Goal:** Improve task management with editing, deletion, and testing.

### Sprint Backlog
- Edit task details (3 story points)
- Delete task (2 story points)
- Test task functions (3 story points)

**Total:** 8 story points

## Definition of Done
- Feature implemented and reviewed.
- Basic test completed.
- Issue status updated in Jira.
- Acceptance criteria satisfied.
