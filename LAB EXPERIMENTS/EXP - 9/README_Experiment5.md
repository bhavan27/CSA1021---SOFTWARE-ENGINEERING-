# Experiment: Creating a Scrum Project with Backlog and Sprint in Jira

## Aim
To create a Scrum project in Jira, prepare a product backlog, plan a sprint, and manage work using Scrum boards.

## Project Example
Student Task Management System

## Procedure
1. Sign in to Jira and create a new project.
2. Select the Scrum project template and name the project.
3. Open the Backlog and create the Epic, stories, and tasks.
4. Add priorities and story points to backlog issues.
5. Create Sprint 1 and move selected issues into it.
6. Set the sprint goal and duration.
7. Start the sprint and update issue statuses on the Scrum board.
8. Review sprint progress and complete the sprint.

## Backlog Items
- Epic: Student Task Management System
- Stories: Create task, View task list, Mark task completed, Edit task details, Delete task
- Tasks: Design task interface, Test task functions

A Scrum project with an organized backlog and sprint plan was created and managed using Jira.
