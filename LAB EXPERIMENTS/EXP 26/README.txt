EXPERIMENT 26: CLONING A GITHUB REPOSITORY AND EDITING FILES LOCALLY

Aim:
To clone an existing GitHub repository to a local system and edit its files using Git.

Requirements:
- Git installed
- GitHub account / repository URL
- Terminal or Command Prompt
- Text editor such as VS Code

Procedure:
1. Open the required GitHub repository.
2. Copy its HTTPS clone URL.
3. Open a terminal in the target directory.
4. Clone the repository using git clone.
5. Navigate into the cloned directory.
6. Open the project files using a text editor.
7. Modify the README or source file.
8. Check changes using git status and git diff.
9. Stage the changes using git add.
10. Commit the changes using git commit.
11. Push the changes to GitHub using git push.
12. Verify the updated file in the GitHub repository.

Result:
The GitHub repository was cloned to the local system, its files were edited, and the changes were committed and pushed back to GitHub.
