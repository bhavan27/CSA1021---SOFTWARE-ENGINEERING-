EXPERIMENT 21: CONTAINERIZING A PYTHON FLASK TO-DO APPLICATION USING DOCKER

Aim:
To develop a simple To-Do web application using Python Flask and containerize it using Docker.

Requirements:
- Python 3
- Flask
- Docker Desktop / Docker Engine
- Web browser

Procedure:
1. Develop a To-Do application using Flask.
2. Create HTML templates and CSS files for the user interface.
3. Create requirements.txt to specify dependencies.
4. Write a Dockerfile to package the Flask application.
5. Build the Docker image using docker build.
6. Run the container and map port 5000.
7. Open the application in a browser.
8. Add, complete, and delete tasks.
9. Verify the container using docker ps.
10. Stop and remove the container after testing.

Result:
A Python Flask To-Do application was successfully containerized using Docker and accessed through a web browser.
