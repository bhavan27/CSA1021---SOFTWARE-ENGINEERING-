EXPERIMENT 28: PULLING COLLABORATOR CHANGES FROM GITHUB

Aim:
To synchronize a local Git repository with changes pushed by a collaborator to GitHub.

Requirements:
- Git installed
- Shared GitHub repository
- Repository cloned locally
- Collaborator has pushed changes
- Terminal or Command Prompt

Procedure:
1. Open the local repository folder.
2. Check the current working tree using git status.
3. Check the current branch.
4. Fetch updates from the remote repository.
5. Review remote commits if required.
6. Pull collaborator changes from the remote branch.
7. Verify synchronization using git status and git log.
8. Open the updated files and inspect collaborator changes.

Result:
Collaborator changes were pulled from GitHub and integrated into the local repository.
