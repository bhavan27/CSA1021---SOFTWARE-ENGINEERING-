EXPERIMENT 28 — PULLING COLLABORATOR CHANGES FROM GITHUB

Prerequisite: Shared GitHub repository cloned locally; collaborator has pushed changes.

1. Open terminal inside the local repository.
2. Check local status:
   git status

3. Check current branch:
   git branch

4. Fetch updates from remote:
   git fetch origin

5. View remote updates (optional):
   git log --oneline HEAD..origin/main

6. Pull collaborator changes:
   git pull origin main

7. Verify updated files:
   git status
   git log --oneline -5

8. Open the updated files in the editor and confirm collaborator changes.

If working on a different branch, replace main with that branch name.

If local changes prevent pulling, commit or stash your changes first:
   git stash
   git pull origin main
   git stash pop

If merge conflicts occur, edit the conflicting files, then:
   git add .
   git commit -m "Resolve merge conflict"
