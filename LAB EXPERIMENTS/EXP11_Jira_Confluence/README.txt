EXP 11 – Linking Jira Issues with Confluence for Progress Tracking

Aim:
To connect Jira issues with a Confluence page and track project progress.

Procedure:
1. Create or open the Jira project and its issues.
2. Create a Confluence page for project progress.
3. Add the Jira issue links or Jira Issues macro to the page.
4. Select the relevant project or issue keys.
5. Display issue summary, status, priority, and assignee.
6. Publish the Confluence page.
7. Open issue links to verify they navigate to Jira.
8. Update issue statuses and review progress from Confluence.

Files:
- Other_Files/Jira_Issues.csv: Sample Jira issue data.
- Other_Files/Confluence_Progress_Page.md: Sample progress page content.
- Output/Progress_Tracking_Dashboard.png: Illustrative dashboard output.
- Screenshots/README.txt: Instructions for adding actual screenshots.

Result:
Jira issues were linked with a Confluence progress page to provide a centralized view of task status.
