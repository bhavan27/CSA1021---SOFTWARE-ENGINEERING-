## How issues are linked
1. Create the Confluence project progress page.
2. Open a Jira issue.
3. Use the issue's link/share option or insert the Jira issue link into the Confluence page.
4. In Confluence, insert a Jira Issues macro/table (if available) and filter by project or issue keys.
5. Save/publish the page.
6. Open the linked issue to verify the connection.
7. Update Jira statuses and refresh the Confluence page to track progress.
